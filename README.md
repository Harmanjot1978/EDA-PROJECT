# New York City Airbnb Analysis & Predictive Modelling 
This repository contains a comprehensive data science workflow analyzing the NYC Airbnd market dataset.

## Projects Included
1. **Exploratory Data Analysis ('EDA_PROJECT.ipynb)**
   *Data cleaning amd handling missing values.
   *visualising price distributions, room type frequencies and geographical insights across neighbourhood.

2. **Predictive Modeling ('NYC.pynb)
   *Implementing a **Linera Regression** model to predict rental prices.
   *Feature engineering and evaluation metrices (RMSE, R^2 score).
   
    ## Technologies used
   * Python
   * Pandas & NumPy
   * Matplotlib & Seaborn
   * Scikit-Learn (Linear Regression)
